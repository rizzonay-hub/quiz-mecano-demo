# Quiz de Serviços — Mêcano

Demonstração de um quiz interativo para captura estruturada de serviços contratados (Holding Complexa / Básica) com integração automática para criação de tarefas e subtarefas no ClickUp via webhook do Make.

## Como visualizar

Acesse a versão publicada em **GitHub Pages** (link na aba "About" do repositório) ou abra o arquivo `index.html` localmente em um navegador.

## Stack

- HTML + CSS + JavaScript (sem dependências externas além do Google Fonts — Inter)
- Identidade visual baseada na marca [Mêcano](https://mecanocontabil.com.br) — vermelho `#F31C46` em gradiente
- Integração: webhook do Make → ClickUp (criação de tarefa cliente + subtarefas por grupo + sub-subtarefas por item)
